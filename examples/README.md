# NSIGII Examples

## Quick Start

```bash
nsigii wrap examples/sample.txt
nsigii inspect examples/sample.txt.nsigii
nsigii verify examples/sample.txt.nsigii
nsigii extract examples/sample.txt.nsigii
```

## Supported Payloads

NSIGII is format-agnostic. Try wrapping:
- `.zip` archives
- `.mp4` videos
- `.wasm` modules
- `.txt` documents
- `.bin` firmware
- Unknown formats
